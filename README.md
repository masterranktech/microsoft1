# Microsoft Homepage Clone

A responsive, pixel-accurate recreation of the Microsoft official homepage. This project demonstrates modern responsive layout strategies, semantic HTML5 structure, CSS Grid and Flexbox mechanics, and mobile-first menu interactions without relying on external UI libraries.

---

## 🌟 Key Features

- **Responsive Grid & Flexbox:** Dynamic product card grids and multi-column footers that rearrange automatically across all screen sizes.
- **Mobile Hamburger Navigation:** Clean toggle interaction built with lightweight vanilla JavaScript and accessible ARIA attributes.
- **Modern Semantic HTML5:** Built using `<header>`, `<nav>`, `<main>`, `<article>`, and `<footer>` for maximum accessibility and SEO structure.
- **Segregated Styling:** Externalized stylesheet using modern CSS custom properties (variables) for consistent colors, spacing, and typography.
- **Smooth Utility Actions:** Fast and smooth scrolling "Back to top" functionality and styled promotional banners.

---

## 🛠️ Tech Stack

- **HTML5:** Semantic architecture, accessible markup
- **CSS3:** Flexbox, CSS Grid, media queries, CSS variables
- **JavaScript (ES6):** Mobile navigation toggle and UI state handling
